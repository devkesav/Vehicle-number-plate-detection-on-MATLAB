# Vehicle Number Plate Detection on MATLAB

## Overview
- This project implements vehicle number plate detection using MATLAB image processing techniques.
- I make the improvement on the pervious orginal version of this matlab script refered by Saravannan G sir.
- `existed project link`: https://www.electronicsforu.com/electronics-projects/hardware-diy/vehicle-number-plate-detection-using-matlab

## Existing features
- Number plate detection and localization
- Image preprocessing and enhancement
- Character recognition capabilities

## Updated features
- Improving OCR && number-plate detection
- To reduce noise to control wrong detection

## Project Files
- `vehicle_number_plate.m` - Main detection script(updated)
- `Vehicle1.jpg` - Sample input image(existed)
- `Fig1 Vehicle1_ouput1.jpg` - Sample output image(existed)

## Requirements
- MATLAB (with Image Processing Toolbox)

## Usage
Run the main script:
```matlab
vehicle_number_plate
```
